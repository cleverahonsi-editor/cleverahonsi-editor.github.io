# Ahonsi Clever — video editing portfolio

Plain HTML/CSS/JS, no build step. Live at https://cleverahonsi-editor.github.io

- `index.html` — the page
- `js/data.js` — every piece: title, format, role, tools. Edit here to change what the site says.
- `media/<id>.mp4` full video, `<id>-loop.mp4` hover preview, `<id>.jpg` poster.
